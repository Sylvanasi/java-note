- Markdown 笔记可以直接在 GitHub 阅读，也可以将本仓库作为 Obsidian 仓库打开。
- 尚未填写的空分类目录通过 `.gitkeep` 保留。
- `.obsidian/`、`.trash/` 和 `.DS_Store` 不纳入版本管理。
